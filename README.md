3. **DM Mono**: Technical metadata, category indices, and small annotations.

## 🚀 Development & Deployment

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle (into dist/)
npm run build

# 4. Preview production build
npm run preview
```

### GitHub Pages Deployment
A GitHub Actions workflow is preconfigured in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). When you push to the `Main` branch and enable GitHub Pages via GitHub Actions in repository settings, the site will automatically build and deploy.
